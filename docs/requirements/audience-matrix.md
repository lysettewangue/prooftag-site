Audiences are **context**, not top-level nav. They appear as blocks on product, expertise, and CT pages.

| ID | Audience | Primary paths | Need |
|----|----------|---------------|------|
| A-01 | Government / MINT / DTR | About, products, CT hub, resources | Institutional positioning; not an operational login |
| A-02 | Inspection-centre operators | CERTIDOCS CT, CT hub, equipment, directory | How the process works; not the live app |
| A-03 | Centre owners / promoters | Reporting (when published), directory | Activity monitoring story — VER-06 |
| A-04 | Transport / logistics professionals | Products, expertise, resources | Solution overview |
| A-05 | Motorists | CT-VERIF, centre directory, contact | Verify a visite; find a centre |
| A-06 | Road-safety NGOs / organisations | DOSER, expertise road safety, resources | Data and prevention narrative |
| A-07 | Insurers | CT-VERIF, resources | Authenticity of inspections — no live queries |
| A-08 | Investors / partners | About, partners, products | Who CATIS is; VER-09 / VER-12 |
| A-09 | Technology partners | Expertise, contact | Integration talk — no public API |
| A-10 | Media / public | News, about, contact | Verified facts only |
| A-11 | Job seekers / interns | Careers, about/team | Listings may be empty at launch |

Admin roles are not public audiences; they are step 018 / 035.
