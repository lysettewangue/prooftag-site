## 1. CERTIDOCS CT (`CERTIDOCS_CT`)

**Audience:** centres, transport authorities, CATIS operations.  
**Public:** after rewrite of verified themes.  
**Themes allowed as starting copy (rewrite required):**

- Software and equipment ecosystem for secured technical inspection in Cameroon.
- Centre server receives test-bench data; generates secured PV and decisions where applicable.
- Secured vignette process (Code à Bulles, QR) as part of the CT security model.
- CATIS supports process quality; it does not replace MINT authority.

**Do not publish:** internal architecture, credentials, undocumented integrations, the name DITROS-CT.
